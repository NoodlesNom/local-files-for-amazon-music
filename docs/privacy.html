Amazon Music Local Files · Version 1.0.0 · October 2, 2026

This page describes the Microsoft Edge extension "Amazon Music Local Files", published by NoodlesNom. The extension is not affiliated with Amazon. The developer collects no data. The Edge Add-ons listing is a draft and has not been submitted.

What it does

  • It is a content script on the English Amazon Music sites: music.amazon.com, .ca, .co.uk, .com.au, .in, and .ae. A toolbar popup and a background service worker run with it.
  • On the Local Files playlist, it reads audio files you pick with the file picker or drop onto the page. It reads title, artist, and cover art from those files in the browser, and plays them with an audio element on that page.
  • Audio bytes are not written to extension storage and are not sent to the developer. They are not stored on a server run by the developer. There is no such server.
  • Extension storage keeps song names, artists, filenames, ids, the Local Files playlist id, shuffle, and a small player session (which song and where playback was). That is text, not the audio.
  • File System Access handles are kept in IndexedDB in the extension and on the Amazon Music page so the same files can be opened again after a reload. A handle is a permission to read a file you already chose. It is not a copy of the audio.
  • If the playlist Local Files uses does not exist, the extension asks Amazon Music, with the sign-in already in that tab, to create a private playlist with no tracks. It can also list that playlist and remove catalog tracks that were added to it. Those requests go to Amazon Music (music.amazon and gql.music.amazon). They do not include your audio files, and they are not sent to the developer.
  • The toolbar popup shows the saved names and can ask the open Amazon Music tab to create that playlist. It does not read other sites. The playlist is private.

What it does not do

  • It does not upload audio to the developer, and it does not store audio bytes on a server.
  • It does not upload your audio files to Amazon.
  • It does not send song names, file paths, or audio to the developer. There is no analytics, no tracker, and no account with the developer.
  • It does not ask for your Amazon password. It uses the session the Amazon Music page already has.
  • It does not read pages that are not Amazon Music.

Permissions

  • storage holds the names and settings above. It does not hold audio bytes.
  • activeTab and tabs let the popup talk to the Amazon Music tab you already have open, and let the extension reload that tab when the page script has to start clean.
  • Host access is limited to the English Amazon Music sites listed above.
