Play your own local files in Amazon Music

Add songs from this computer and play them on the Local Files playlist.

Audio stays on this computer. The extension does not upload it.

What it does

On the Local Files playlist in Amazon Music. Playback uses the files you pick.

+

Add songs

On the Local Files page, Add songs opens a file picker. You can also drag audio files onto the Amazon Music page. mp3, m4a, mp4, flac, wav, ogg, aac, opus, and webm are accepted.

♪

Plays on this computer

Play and pause, seek, next and previous, shuffle, repeat, a queue, and volume. The audio element plays the file locally. Nothing is uploaded.

Aa

Title, artist, and cover

Tags and cover art are read from the file in the browser. If a file has no tags, a name like Artist - Title is used. You can rename a song in the list.

#

Sort and search

Sort by title A to Z, title Z to A, or added order. Search the local song names on the playlist page.

◎

An anchor playlist

The page is a real Amazon playlist titled LOCAL PLACEHOLDER, shown as Local Files. It is created public and empty if it is missing. Catalog tracks that land on it are removed. Your audio is not uploaded into it.

☰

Toolbar list

The toolbar popup lists song names only, not the audio. It can create the LOCAL PLACEHOLDER playlist when Amazon Music is already open.

Load unpacked (Edge, Chrome, and other browsers)

  1. Download the ZIP from the latest release and unzip it (or clone the repo).
  2. Open edge://extensions (in Chrome: chrome://extensions).
  3. Turn on Developer mode.
  4. Click Load unpacked and pick the folder that contains manifest.json.
  5. Open Amazon Music and the Local Files playlist. Use Add songs, or drag files onto the page.

Where it runs

English Amazon Music sites only: music.amazon.com, .ca, .co.uk, .com.au, .in, and .ae. The Local Files view is the playlist titled LOCAL PLACEHOLDER.

Picked files are remembered as file handles in this browser so you do not have to choose them again after a reload. The audio itself is not copied into the extension.

Privacy

No account with us

There is no sign-in to the developer, no analytics, and no server of ours. Removing the extension removes it.

Audio stays here

The extension reads files you pick and plays them in the browser. It does not upload audio to the developer and does not store audio bytes on a server. Extension storage keeps names, not the files.

Amazon, only for the anchor

Finding or creating the empty LOCAL PLACEHOLDER playlist uses the Amazon Music sign-in already open in that tab. Those requests do not include your audio.
